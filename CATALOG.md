# 🧰 Картотека инструментов Claude Code

Постоянный реестр всех инструментов: **скиллы**, **плагины**, **MCP-серверы**.
Источник правды — этот файл (виден на GitHub с любого устройства). Живая копия
лежит в `~/.claude/tools-catalog.md`.

Обновляется скиллом **`tools-catalog`** (вызов: «покажи мои инструменты»,
«обнови картотеку», `/tools-catalog`). Каждый вызов пересобирает картотеку
заново — она всегда свежая.

> Файловый слой собирает `catalog.py`; MCP-серверы и плагины, которые в
> облаке инжектит харнесс, Claude добавляет из контекста текущей сессии.

_Последнее обновление: 2026-06-13_

### Как обновлять картотеку

- **Через скилл:** «покажи мои инструменты» / «обнови картотеку» / `/tools-catalog`.
- **Вручную (только файловый слой):**
  ```bash
  python3 plugins/daniil-skills/skills/tools-catalog/catalog.py --out ~/.claude/tools-catalog.md
  ```
- После добавления нового скилла/плагина/MCP — просто вызови картотеку, и он попадёт в таблицу.
