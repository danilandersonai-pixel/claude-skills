# 🧰 Картотека инструментов Claude Code

Постоянный реестр всех инструментов: **скиллы**, **плагины**, **MCP-серверы**.
Источник правды — этот файл (виден на GitHub с любого устройства). Живая копия
лежит в `~/.claude/tools-catalog.md`.

Обновляется скиллом **`tools-catalog`** (вызов: «покажи мои инструменты»,
«обнови картотеку», `/tools-catalog`). Каждый вызов пересобирает картотеку
заново — она всегда свежая.

> Файловый слой собирает `catalog.py`; MCP-серверы берутся из реестра
> `claude-mcp`; то, что в облаке инжектит харнесс, Claude добавляет из
> контекста текущей сессии.

_Последнее обновление: 2026-06-14_

## MCP-серверы

Источник правды — реестр `mcp-catalog.json` в репо
[`claude-mcp`](https://github.com/danilandersonai-pixel/claude-mcp).
Подключи `claude-mcp` к сессии — и `catalog.py` подхватит серверы автоматически.

### Реестр `claude-mcp` (6) — твои настроенные серверы

| Инструмент | Транспорт | env-ключи | Описание |
|---|---|---|---|
| `brave` | http | — | Веб-поиск через Brave Search |
| `context7` | stdio | `CONTEXT7_API_KEY` | Актуальная документация библиотек и фреймворков |
| `github` | stdio | `GITHUB_PERSONAL_ACCESS_TOKEN` | Репозитории, issues, pull request'ы, код |
| `googlesheets` | http | — *(OAuth)* | Чтение и запись данных в Google Таблицах |
| `magic` | stdio | `MAGIC_API_KEY` | Генерация UI-компонентов (21st.dev Magic) |
| `stitch` | http | `STITCH_GOOGLE_API_KEY` | Генерация UI/дизайна экранов (Google Stitch) |

> Все ключи — через env-переменные, в репо только их имена, без значений.
> Локальные `blender` и `chrome-devtools` намеренно исключены (нужны железо/браузер).

### Подключены платформой в облачной сессии (5) — зависят от окружения

> Эти серверы инжектит облако и они эфемерны — на десктопе списка может не быть.

### Как обновлять картотеку

- **Через скилл:** «покажи мои инструменты» / «обнови картотеку» / `/tools-catalog`.
- **Вручную (только файловый слой):**
  ```bash
  python3 plugins/daniil-skills/skills/tools-catalog/catalog.py --out ~/.claude/tools-catalog.md
  ```
- После добавления нового скилла/плагина — просто вызови картотеку, и он попадёт в таблицу.
- **Новый MCP:** добавь его в `mcp-catalog.json` репо `claude-mcp` → вызови картотеку. Сервер подхватится автоматически (если `claude-mcp` подключён к сессии).
